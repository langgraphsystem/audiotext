# CLAUDE.md

Telegram-бот **ChatGPT Luna**: принимает ссылку на TikTok или Instagram, достаёт
текст и картинку из ролика и возвращает разбор контента. Дополнительно копит базу
по списку отслеживаемых аккаунтов.

## Команды

```bash
pip install -r requirements.txt   # зависимости
python test_setup.py              # проверка окружения (зависимости, FFmpeg, ссылки)
python -m app.bot                 # запуск (polling)
python -m app.bot --webhook       # запуск в режиме webhook
make lint                         # компиляция всех модулей
```

Тестового фреймворка нет. Проверять изменения — через `test_setup.py` и точечные
скрипты с моками (сетевые вызовы из среды разработки недоступны).

## Архитектура

```
handlers.py      обработчики Telegram; одна ссылка → полный разбор
collector.py     плановый обход аккаунтов, тот же конвейер
video_processor.py  оркестрация: субтитры → аудио → кадры → анализ
yt_dlp_client.py    скачивание субтитров, аудио и превью для кадров
audio.py         FFmpeg: перекодирование, длительность, нарезка, проверка дорожки
vision.py        FFmpeg: ключевые кадры → data URL
stt_engine.py    расшифровка с разбиением на части и склейкой таймлайна
stt_openai_api.py обёртка над OpenAI Audio API
openai_client.py анализ (Responses API), мультимодальный ввод
storage.py       SQLite: собранные публикации, дедупликация
export.py        выгрузка материала одним Markdown-файлом
sources.py       разбор списка аккаунтов и лент профилей
```

## Что нужно знать, прежде чем менять код

**Сборка только через Dockerfile.** В образе стоит FFmpeg, без него не работают ни
длинные видео, ни кадры, ни проверка аудиодорожки. `railway.toml` фиксирует
`builder = "DOCKERFILE"`; переключение на Nixpacks/Railpack ломает половину функций.

**Лимит загрузки в OpenAI Audio API — 25 МБ.** Отсюда `MAX_UPLOAD_SIZE_MB=24`,
перекодирование в моно-MP3 64 кбит/с и нарезка на части. `MAX_FILE_SIZE_MB` (500) —
это про размер скачанного файла, не путать.

**`gpt-transcribe` не поддерживает `verbose_json`**, то есть таймкодов сегментов не
даёт. Модели этого семейства помечены в `stt_openai_api.py`; не пытайтесь снова
запрашивать у них сегменты. Таймкоды есть только у `whisper-1`.

**Ролик без речи — нормальный случай.** Немых Reels много. Любой сбой расшифровки
не должен прерывать обработку: разбор продолжается по кадрам и метаданным.
Прерываемся только если нет ни речи, ни кадров.

**Polling допускает один экземпляр.** Две реплики (или локальный запуск рядом с
продом) дают `TelegramConflictError`. В `railway.toml` стоит `numReplicas = 1`.

**Диск контейнера эфемерный.** SQLite с собранным материалом обнуляется при
редеплое, если не подключён volume и не задан `DATABASE_PATH`.

**Настройки читаются по имени поля.** В pydantic-settings v2 kwarg `env=` не
работает: имя переменной окружения — это имя поля в верхнем регистре. Где нужно
другое имя (например `PORT`), стоит явный `validation_alias`.

**Временные файлы.** Всё скачанное складывается в `WORKDIR` и удаляется через
`cleanup_temp_files`. При выходе по исключению чистить обязательно — иначе файлы
копятся на эфемерном диске до заполнения.

## Стиль

Комментарии — по-английски и только там, где объясняют *почему*, а не *что*.
Сообщения пользователю и логи — по-русски. Новые настройки добавляются в
`config.py`, `env.example` и таблицу в `README.md` одновременно.
