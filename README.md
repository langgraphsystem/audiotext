# 🌙 ChatGPT Luna — анализатор видеоконтента

Telegram-бот, который принимает ссылку на **TikTok** или **Instagram** видео, достаёт текст
(субтитры или расшифровку речи) и возвращает профессиональный анализ контента.

## 🚀 Возможности

- **📝 Субтитры**: автоматически находит и скачивает доступные субтитры/captions
- **🎵 Расшифровка аудио**: если субтитров нет — скачивает **только аудиодорожку** и расшифровывает её
- **♾️ Длинные видео**: аудио перекодируется в компактный моно-MP3 и режется на части,
  поэтому ролики на десятки минут больше не отваливаются по лимиту загрузки
- **🧠 Анализ ChatGPT Luna**: резюме, чеклист, проблема/решение/выгода, кэпшн, инсайты,
  хэштеги, мини-статья и JSON-блок
- **⏱️ Таймкоды**: ключевые моменты с временными метками в формате `мм:сс`
- **📊 Отчёт файлом**: готовый текстовый отчёт прямо в чат

## 🌐 Поддерживаемые ссылки

| Платформа | Примеры |
|-----------|---------|
| TikTok | `https://www.tiktok.com/@user/video/...`, `https://vt.tiktok.com/...`, `https://vm.tiktok.com/...` |
| Instagram | `https://www.instagram.com/reel/...`, `/p/...`, `/tv/...` |

Для закрытых аккаунтов и возрастного контента Instagram укажите файл cookies
(`INSTAGRAM_COOKIES_FILE`) в формате Netscape.

## 📋 Требования

- **Python 3.11+**
- **FFmpeg** — обязателен: без него длинные видео обработать не получится
- Токен Telegram-бота (@BotFather) и ключ OpenAI API

Зависимости Python перечислены в `requirements.txt`:
`aiogram`, `yt-dlp`, `openai`, `pydantic`, `pydantic-settings`, `httpx`, `aiohttp`, `uvloop` (Linux).

## ⚙️ Конфигурация

Все параметры задаются переменными окружения (см. `env.example`).

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BRAND_NAME` | `ChatGPT Luna` | Имя ассистента во всех сообщениях и отчётах |
| `OPENAI_MODEL` | `gpt-5.1` | Модель анализа (Responses API) |
| `OPENAI_REASONING_EFFORT` | `medium` | `none/low/medium/high` — глубина рассуждений |
| `OPENAI_VERBOSITY` | `medium` | `low/medium/high` — длина ответа |
| `STT_MODEL` | `whisper-1` | Модель расшифровки; `whisper-1` даёт таймкоды |
| `STT_LANGUAGE` | `auto` | Язык расшифровки или автоопределение |
| `AUDIO_BITRATE` | `64k` | Битрейт моно-MP3 для расшифровки |
| `AUDIO_CHUNK_SECONDS` | `600` | Длина куска при разбиении длинного аудио |
| `MAX_UPLOAD_SIZE_MB` | `24` | Лимит одной загрузки в OpenAI Audio API (жёсткий максимум 25 МБ) |
| `MAX_FILE_SIZE_MB` | `500` | Предохранитель на размер скачанного файла |
| `MAX_AUDIO_DURATION_MINUTES` | `120` | Максимальная длительность ролика |
| `INSTAGRAM_COOKIES_FILE` / `TIKTOK_COOKIES_FILE` | — | Cookies для закрытого контента |

## 🧠 Как это работает

```
Ссылка (TikTok / Instagram)
        │
        ├─ 1. yt-dlp: проверка субтитров ──► есть? ──► текст
        │
        └─ 2. yt-dlp: скачивание аудиодорожки (без видео)
                 │
                 ├─ FFmpeg: моно-MP3 16 кГц, 64 кбит/с
                 ├─ больше лимита? ──► нарезка на части по AUDIO_CHUNK_SECONDS
                 └─ OpenAI Audio API: расшифровка каждой части
                          │
                          └─ сегменты сдвигаются на смещение части (единый таймлайн)
        │
        3. ChatGPT Luna (Responses API): структурированный анализ
        │
        4. Telegram: текст расшифровки + файл отчёта
```

### Почему длинные видео теперь проходят

Раньше для TikTok скачивался целиком MP4 и отправлялся в API как есть, а лимит
загрузки составляет 25 МБ — длинные ролики падали с ошибкой. Теперь скачивается
только аудио, оно перекодируется в компактный моно-MP3 (≈0,5 МБ в минуту) и при
необходимости режется на части, которые расшифровываются последовательно и
склеиваются в один транскрипт с корректными таймкодами.

## 📁 Структура проекта

```
app/
├── bot.py             # точка входа: polling и webhook
├── handlers.py        # обработчики Telegram-сообщений
├── video_processor.py # оркестрация: субтитры → аудио → анализ
├── yt_dlp_client.py   # скачивание субтитров и аудио (TikTok, Instagram)
├── audio.py           # FFmpeg: перекодирование, длительность, нарезка
├── stt_engine.py      # расшифровка с разбиением на части и склейкой
├── stt_openai_api.py  # обёртка над OpenAI Audio API
├── openai_client.py   # анализ контента (Responses API)
├── config.py          # настройки из переменных окружения
├── rate_limiter.py    # лимиты запросов на пользователя
├── utils.py           # определение платформы, субтитры, файлы
└── logger.py          # логирование
```

## 🧪 Проверка

```bash
python test_setup.py
```

Скрипт проверяет версию Python, зависимости, наличие FFmpeg/FFprobe, структуру
проекта и корректность распознавания ссылок обеих платформ.

## 🩺 Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| `FFmpeg не найден` | Установите ffmpeg и убедитесь, что он в `PATH` |
| Instagram: «не удалось получить данные видео» | Запись приватная или нужен `INSTAGRAM_COOKIES_FILE` |
| Пустая расшифровка | В ролике нет разговорной речи (только музыка) |
| Ошибка лимита загрузки | Уменьшите `MAX_UPLOAD_SIZE_MB` или `AUDIO_CHUNK_SECONDS` |
